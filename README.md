# PhoneMirror V1 - Fresh Build

This UI is a new implementation written for this project. It does not reuse the previous GUI source.

## Design
- Very rounded cards and controls
- Dark navy base
- Green primary action
- Three-step workflow
- Quality presets
- Simple connection workflow
- Expert settings kept out of the main path
- Kill switch only targets processes started by this app instance

## Run
Double-click `START_PHONEMIRROR_V5.bat`.

This source build requires Python 3. `adb.exe` and `scrcpy.exe` are bundled when available from the previous package.

## Important
The UI and application logic are newly written. The scrcpy/ADB binaries are runtime dependencies, not the UI source.
